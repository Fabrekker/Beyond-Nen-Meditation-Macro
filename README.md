# Beyond Nen Macro

A Windows macro for the Beyond Nen training minigame on Roblox.

- Automatic target and Nen color detection.
- Timed clicks and feedback-based adjustments.
- Live preview with an optional preview-only mode.
- F1 to start or pause; F2 to stop.
- Updates through GitHub Releases while keeping your settings.

Requires Windows and Python 3.12. Open **Start Macro.cmd** to launch or **Update Macro.cmd** to update. Configure the game and feedback areas before starting.
